# 6색 고양이 타일 적용

2026-10-04. 승인된 빨강·노랑·초록·파랑·보라·주황 고양이 라운드 사각 타일을 퍼즐 테마로 연결했습니다.

## 원본과 렌더링

- `sprites/cats/colored-cat-tokens-v4.png`: 승인 원본을 수정 없이 보존
- SHA-256: `309463da9235aea05d8cc0398508c3d02e2b0a534a2258f3940bd14558ad47c6`
- `puzzle-atlas-data.js`: 같은 PNG 바이트의 base64 표현. 로컬 파일 실행에서도 Canvas/Pixi가 origin-clean인 이미지 입력을 쓰도록 함
- `puzzle-theme.js`: 여섯 색상/이름/팔레트/atlas 좌표
- `puzzle-tile-renderer.js`: 원본 크기로 라운드 마스크를 캐시한 뒤 축소. 이미지 파일을 자르거나 배경을 편집한 것이 아니라 게임 실행 중 Canvas 코드로 필요한 영역만 표시

3×2 atlas의 각 사각형은 원본 픽셀 좌표이며 radius는 100입니다:

|---|---:|---:|---:|---:|

| 노랑 | 543 | 52 | 444 | 437 |
| 초록 | 1011 | 52 | 445 | 436 |
| 파랑 | 78 | 509 | 443 | 434 |
| 보라 | 543 | 510 | 443 | 434 |
| 주황 | 1011 | 508 | 444 | 436 |

흰 배경과 바깥 그림자는 마스크 밖에 남습니다. 마스크 경계 ±2px의 최소 RGB 채널 차이는 109/141/64/128/95/146이고, 외부의 중립색 영역과 연결되어 마스크 안에 들어온 픽셀은 여섯 영역 모두 0개입니다. 눈의 흰 하이라이트는 유지됩니다. 축소 필터가 원본의 흰 배경을 섞지 않도록 반드시 원본 해상도의 투명 Canvas에 먼저 캐시합니다.

## 연결 범위

보드 타일, 레벨 목표 아이콘, 목표 달성 이름, +1 목표 표시, 매치/연쇄 입자, 무지개 특수효과 팔레트가 같은 논리 인덱스의 6색 테마를 사용합니다. 선택 표시도 라운드 사각 타일에 맞췄고, Canvas와 Pixi 양쪽에서 타일 위에 그립니다. 이미지 로드 실패/지연 시 이전 커피/과일 이미지 대신 해당 색 이름을 가진 임시 타일을 표시합니다.

원래 0~5 숫자 인덱스, 8개 레벨 조건, 저장 키, 보상, 시설 비용, 카페 모델은 바꾸지 않았습니다.
